# Ariad: Breast

**A breast cancer treatment side-effect companion**  
**A trusted thread through treatment**

> Unreviewed Build Week prototype. Not for clinical use.

Ariad helps adults receiving systemic therapy for breast cancer move from a
treatment or symptom to treatment-aware education, fixed warning information,
and a neutral summary they can choose to share with their cancer team.

The complete judge-ready README is being built alongside the first vertical
slice. See [BUILD_WEEK.md](./BUILD_WEEK.md) for timestamped implementation
evidence and [AGENTS.md](./AGENTS.md) for the enforced safety boundary.
